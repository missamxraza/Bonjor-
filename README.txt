BONJOR V3 — PAKISTAN

This version is made for a Pakistan-based clothing brand.

Important:
1. Keep index.html, style.css, script.js and all JPG/PNG image files in the SAME GitHub repository folder.
2. The image paths intentionally use root names such as hero.jpg, not assets/hero.jpg.
3. In script.js, replace WHATSAPP_NUMBER with your Pakistan WhatsApp number:
   Example: 923001234567
4. Prices are shown in PKR.
5. The site mentions Cash on Delivery and Pakistan-wide shipping.
6. This is a front-end/demo store. Real payment processing, order database and courier integration are not included yet.
